Non-trivial AI contributions are not acceptable in this project. This includes
contributions to code (whether Java or Scala or Lua), art assets (graphics or
sounds), translations, and documentation (both in game such as the manual and out
of game such as PR descriptions).

This project does currently does contain AI-generated changes, but the main
authors are actively working to remove all of it as part of the project
modernization efforts, so further AI-generated changes go directly against that
directive.

AI-generated works are based on sources of unknown origin and present potential
copyright ownership issues. The best way to respect all parties involved is to
reject further uses of AI in this project and remove what already exists. This
policy mirrors similar ones to SDL and UZDoom.
